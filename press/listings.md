## 1. AlternativeTo

https://alternativeto.net — where people search for "alternatives to X". Sign up, verify the e-mail, then user menu > **Suggest new application**. Developers may add their own apps. The review queue is slow; a one-time 5 USD priority review is usually done in 1–2 business days (no promise of approval). Descriptions must not contain links, e-mail addresses or phone numbers: links go in their own fields.

The obvious extra entry under "Alternative to" is PowerPoint's presenter view, since that's how people search; we keep PowerPoint off the website, so ask the user before adding it here.

**Description** (no links):

> PDF Diva presents a PDF like any slide deck. The audience sees the slide full screen on black, with no controls. The speaker sees the current slide, the next one, a timer and the page count, readable at a distance and in a dark room.
>
> It was made for venue technicians and video operators: the tool you keep installed for when a speaker turns up with a PDF. It uses the standard presentation keys (Page Up, Page Down, the arrow keys, F5, B for a black screen), so any presentation remote works.
>
> Each display can show the slide or a speaker view, for example one for the technician and one for the speaker, and that can be changed during the talk without stopping it. If a display is disconnected, the presentation carries on.
>
> It needs no setup and no other software: the PDF renderer is built in. No account, no telemetry and no internet connection. Interface in eight languages.

**Platform notes**

- Windows: Windows 10 and 11, from the Microsoft Store (also `winget install "PDF Diva"`) or with an unsigned installer from GitHub.
- Mac: macOS 13 or later, Apple silicon and Intel; not notarized, so the first time it needs Open Anyway in Privacy & Security.
- Linux: a .deb for Debian, Ubuntu and derivatives (64-bit), running on X11.

**Features** (if the form asks for them): Presenter view, Multi-monitor support, Presentation remote support, Works offline, No tracking, Dark mode, Password-protected PDFs.

## 2. Uptodown

https://uptodown.dev (Developers Console) — a big download site, especially in Spanish-speaking countries. Free to register and publish, Windows and Mac. **Add new app**, choose the operating system, upload the file, then fill in the listing. It needs one entry per system: Windows (`PDF-Diva-Windows-1.5.0.exe`) and Mac (`PDF-Diva-macOS-1.5.0.dmg`). Each new version has to be uploaded again from the console.

Uptodown has an edition per language; give it at least English and Spanish:

**Short description (English)**

> A presenter view for any PDF, with the next slide and a timer.

**Short description (Spanish)**

> Presenta cualquier PDF con vista del orador, diapositiva siguiente y cronómetro.

**Description (English)**

> Sooner or later, a speaker hands you a PDF. PDF viewers can go full screen, but they have no presenter view, so the speaker ends up reading the slides off the screen behind them.
>
> PDF Diva presents a PDF like any slide deck. The audience sees the slide; the speaker sees the current slide, the next one, a timer and the page count. It works with any presentation remote, blacks out the screen with one key and keeps going if a display cable comes loose. You choose what each display shows, even during the talk.
>
> It needs no setup and no other software. No account, no telemetry, no internet connection. Free and open source (GPL-3.0), for Windows, Mac and Linux, with the interface in eight languages.

**Description (Spanish)**

> Tarde o temprano, un ponente te da un PDF. Los visores de PDF tienen pantalla completa, pero no vista del orador, así que el ponente acaba leyendo las diapositivas en la pantalla que tiene detrás.
>
> PDF Diva te deja usar un PDF como cualquier presentación. El público ve la diapositiva; el ponente ve la diapositiva actual, la siguiente, un cronómetro y el número de página. Funciona con cualquier pasador, pone la pantalla en negro con una tecla y sigue funcionando si se suelta un cable de vídeo. Tú eliges qué muestra cada monitor, incluso durante la charla.
>
> No necesita configuración ni otros programas. Sin cuenta, sin telemetría y sin conexión a internet. Gratuita y de código abierto (GPL-3.0), para Windows, Mac y Linux, con la interfaz en ocho idiomas.

**Category**: Office / Presentations (or the closest one). **Video**: the YouTube link above.

## 3. MajorGeeks

> **Subject:** Software submission: PDF Diva 1.5.0 (free, open source)
>
> Hello,
>
> I'd like to submit PDF Diva, a free and open-source presenter view for PDF files.
>
> It presents a PDF like any slide deck: the slide full screen on the projector, and the current slide, the next one and a timer on the speaker's screen. It works with any presentation remote, lets you choose what each display shows, and keeps going if a display is unplugged. No account, no telemetry and no internet connection.
>
> - Website: https://pdfdiva.nilovelez.com/
> - Download (Windows installer, 64-bit): https://github.com/nilovelez/pdf-diva/releases/download/v1.5.0/PDF-Diva-Windows-1.5.0.exe

> - Source code (GPL-3.0): https://github.com/nilovelez/pdf-diva
> - Requirements: Windows 10 or 11, 64-bit
>
> The installer isn't digitally signed, so SmartScreen shows a warning the first time; the Microsoft Store version is signed by Microsoft. Testing it needs only a PDF file; a second display shows the speaker view.
>
> Thank you,
> Nilo Vélez
