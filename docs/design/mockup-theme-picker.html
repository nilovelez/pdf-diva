Theme picker (milestone 11 mockup)

  • The segmented control (System / Light / Dark) becomes three cards, each with a small reader window drawn in CSS with that theme's colours. System is split on the diagonal: light and dark.
  • The chosen card has an accent border, a soft accent background, a check mark and its name in bold. The theme still applies instantly, with no Apply button.
  • Same texts as today (no new strings to translate). The cards share the width equally, so longer names wrap instead of breaking the layout.
  • The dialog below works: click a card (or use the arrow keys) and the dialog changes theme. System follows your own system theme.

Implementation notes (for later)

  • Only launcher/index.html and launcher.css change; launcher.ts keeps the same data-theme buttons, switching aria-pressed for role="radio" + aria-checked in a role="radiogroup", with arrow keys.
  • The mini windows are plain CSS (no images), with the light and dark tokens scoped to each card, so they always show their own theme whatever the app theme is.
  • The PDF page in the preview keeps its paper colour in both themes, as in the real reader.
