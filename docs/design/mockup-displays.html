Configure displays (milestone 9 mockup)

  • One display: the reader shows only Present. It opens the audience view full screen, with no buttons (like any PDF viewer in full screen); the speaker uses the keyboard shortcuts or a slide clicker.
  • Two or more displays: the reader shows Configure displays and Present. Present is the main action (accent colour). There is no separate "Mirror" button any more: setting every display to Audience View is mirroring.
  • Configure displays is its own dialog. It shows the displays in a row (main display first, then left to right), each with its number, "Main" badge, resolution and scale, name and a role selector below. Names are the system's; the built-in display of a laptop is called "Built-in display" and drawn as a laptop. Changes are applied only with Apply, which is enabled when something changed and there is at least one Audience View.
  • Settings (gear) keeps only theme and language, applied instantly as today.
  • The selectors in the dialogs below work, so you can try the rules. Light/dark follows your system.

Reader toolbar

Top: one display. Bottom: two or more. The toolbar updates by itself when a display is connected or disconnected. F5 and Shift+F5 do the same as Present.

2 displays, defaults

Defaults: the main display shows the speaker view, the other one the audience. Apply stays disabled until something changes.

3 displays, defaults

Defaults with three displays: two speaker views (technician and speaker) and the audience on the last display (main display first, then left to right).

3 displays, changed: every display shows the audience (mirror)

Changed displays are highlighted, and Apply is enabled. Every display in Audience View is valid: that is mirroring.

3 displays, invalid: no audience

With no display in Audience View, a message appears and Apply is disabled.

Speaker view toolbar

"Swap screens" is replaced by "Configure displays" (only with two or more displays). It opens the same dialog over the speaker view; Apply moves the windows without stopping the presentation. The timer is shared by every speaker view.
